# Задание 9 по Модулю 3. Семафоры (POSIX).  
За основу взята программа из Задания 8 Модуля 3.  
В программе семафоры System V были заменены на семафоры POSIX.  
Основная логика работы программы осталась без изменений, за исключением того что для управления доступа ко всем файлам (если запустить несколько производителей и потребителей) будет использован один именованный POSIX-семафор.  

По сути отличается лишь то как работает семафор внутри, и также какой код нужно написать для его создания, использования и удаления.  
В данном случае работать с POSIX-семафором оказалось даже проще и понадобилось меньше переменных и строк кода.

Также отличием является то, что в Linux POSIX-семафоры создаются в каталоге /dev/shm.  
А System V-семафоры хранятся в специальной таблице IPC-объектов.  

Для сборки программы написан Makefile  
 - Компиляция и сборка 
    >make
 - Запуск процесса-производителя
    >./producer \<filename.txt\>
 - Запуск процесса-потребителя
    >./consumer \<filename.txt\>
 - Удаление скомпилированных и .txt файлов 
    >make clean
