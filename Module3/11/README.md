# Задание 11 по Модулю 3. Разделяемая память (POSIX).  
За основу взята программа из Задания 10 Модуля 3.  
Логика программы осталась прежней, изменён способ взаимодействия с разделяемой памятью.  
Использован синтаксис для POSIX-shared-memory.  
Также разделяемая память POSIX использует специальную файловую систему tmpfs, которая обычно монтируется в /dev/shm.  
В свою очередь разделяемая память System V хранится в оперативной памяти ядра Linux.  

Для сборки программы написан Makefile  
 - Компиляция и сборка 
    >make
 - Запуск программы
    >./main
 - Удаление скомпилированных и .txt файлов 
    >make clean
