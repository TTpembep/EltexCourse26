# Задание 6 по Модулю 3. Очереди сообщений (System V).  
Реализовано две программы - Сервер и Клиент.  
Сервер создаёт очередь сообщений и ожидает сообщений от пользователей.   
При получении сообщения обрабатывает его: Проверяет есть ли пользователь в списке подключённых клиентов, и не является ли это сообщение служебным словом (например "shutdown" для отключения). Затем добавляет идентификатор отправителя к сообщению и рассылает его остальным подключенным пользователям.  

Клиенты могут подключаться к серверу и отправлять сообщения серверу также через очередь. При отправке сообщения происходит проверка на наличие сообщений в очереди, которые предназначены данному пользователю и соответственно вывод их в консоль.  
Нажатием enter можно проверить пришли ли новые сообщения, ничего при этом не отправляя  

При запуске программы клиенты должны выбрать свой идентификатор. Предусмотрена проверка чтобы он значения id соответствовали условиям: не равно 10 (id сервера), но кратно 10. То есть допустимые идентификаторы: 20, 30, 40...  

Для сборки программы написан Makefile
 - Компиляция и сборка 
    >make
 - Запуск сервера 
    >./main
 - Запуск клиента
    >./client \<id\>
 - Удаление скомпилированных файлов 
    >make clean

Просмотр информации о текущем состоянии IPC операционной системы:  
>ipcs  

Просмотр информации об IPC очередях сообщений System V:  
>ipcs -q -tclup --human

Удаление очереди с заданным идентификатором:  
>ipcrm msg \<id-number\>
