# Задание 8 по Модулю 3. Семафоры (System V).  
Реализовано ддве программы.  
Процесс-производитель создаёт файл с названием указанным в аргументе запуска.  
Затем, с использованием названия файла, создаёт ключ для семафора. И создаёт семафор.  
Обращение к файлу происходит после проверки того что семафор свободен. Блокирует семафор.
После чего начинает открывает записывать в файл построчно наборы из случайного количества случайных чисел. Закрывает файл и разблокирует семафор. Продолжает выполнять циклы до тех пора, пока не получит сигнал прерывания (SIGINT, ^C). При получении сигнала удаляет семафор и завершает работу  

Процесс-потребитель обращается к семафору, с ключём который соответствует названию файла (указан в аргументе запуска). Когда семафор свободен, открывает файл и читает из него построчно все данные. Затем анализирует строки. Если есть необработанные строки (с отметкой "0"), в каждой строке находит минимальное и максимальное значение, выводит эти значения, саму строку, а также id-процесса и название файла на экран. После обработки всех строк, открывает и перезаписывает весь файл. Освобождает семафор.  

Может быть запущено несколько экземпляров потребителей для одного файла.  

Также можно запускать несколько экземпляров производителей, с указанием разных имен файла в аргументы запуска. Для управления доступа к каждому файлу используется "свой" семафор.  

Для сборки программы написан Makefile
 - Компиляция и сборка 
    >make
 - Запуск процесса-производителя
    >./producer \<filename.txt\>
 - Запуск процесса-потребителя
    >./consumer \<filename.txt\>
 - Удаление скомпилированных и .txt файлов 
    >make clean
