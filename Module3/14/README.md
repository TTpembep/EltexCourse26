# Задание 14 по Модулю 3. RAW сокеты.  
Реализована программа, которая получает копии пакетов, предназнааченных приложению-серверу из задачи 12 (сниффер).  
При запуске создаёт RAW-сокет. Затем в цикле начинает ждать UDP-пакет. В буфер попадает IP-заголовк, UDP-заголовок и полезная нагрузка пакета.  
Заголок IP и UDP разбираются чтобы извлечь номера портов и определить нужный ли это пакет.  

Если в пакете указан необходимый нам порт, тогда его содержимое сохраняется в бинарный файл. А также отделяются полезные данные и выводятся в консоль в человекочитаемом виде.

Тестовые запуски программы приведены в скриншотах.

Для сборки программы написан Makefile  
 - Компиляция и сборка 
    >make
 - Запуск программы
    >./main
 - Удаление скомпилированных файлов и бинарного дампа данных
    >make clean
