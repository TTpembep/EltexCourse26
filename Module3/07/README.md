# Задание 7 по Модулю 3. Очереди сообщений (POSIX).  
Реализовано две программы, которые используют две очереди сообщений для двухстороннего взаимодействия (персональный чат).  

Сообщение отправляются по очереди (пинг-понг). Клиент 1 всегда является инициатором диалога  
Клиент 1 при запуске создаёт две очереди сообщений. Если она были ранее созданы - удаляет их и пересоздаёт.  
Затем пользователь может ввести сообщение и отправить его. После чего будет ожидать сообщение от клиента 2.

Клиент 2 при запуске пробует получить дискрипторы очередей, заданных в файле "settings.h", чтобы "подключиться" к чату.  
При успешном получении дискрипторов ожидает сообщения из очереди "queue1". После получения и успешной обработки сообщения, пользователь может ввести ответное сообщение.  

Любой из клиентов может отправить служебное слово "shutdown" для завершения обмена сообщениями. Работа программ обоих клиентов будет завершена.   

В файле "setting.h" задаются основные настройки чата: названия очередей, максимальный размер сообщения, приоритет стандартных и служебных сообщений.

Для сборки программы написан Makefile
 - Компиляция и сборка 
    >make
 - Запуск клиента1
    >./client1
 - Запуск клиента2
    >./client2
 - Удаление скомпилированных файлов 
    >make clean
