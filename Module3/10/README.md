# Задание 10 по Модулю 3. Разделяемая память (System V).  
За основу взята программа из Задания 8 Модуля 3.  
Две программы объединены в одну и разделены на процессы.
При запуске "main.c" происходит создание сегмента разделяемой памяти.  
Затем создаётся дочерний процесс.
Родительский процесс создаёт набор чисел, помещяет их в разделяемую память и меняет значение переменной "state", которая находится в общей памяти.  
Дочерний процесс отслеживает это, и когда "state" равно "1", он отбирает в наборе чисел минимальное и максимальное значение и записывает их в разделяемую память. После чего родительский процесс выводит найденные значений на экран. А также подсчитывает количество итераций обработки.  
Цикл программы повторяется до тех пор пока не поступит сигнал прерываний (^C, SIGINT), после чего выводится количество обработанных наборов данных и программа завершает работу.

Для сборки программы написан Makefile  
 - Компиляция и сборка 
    >make
 - Запуск программы
    >./main
 - Удаление скомпилированных и .txt файлов 
    >make clean
