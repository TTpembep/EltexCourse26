# Кросс-задание 1 по Модулю 3. RAW сокеты + САОД + signals  
За основу была взята программа из задания 12, модуля 3.  
Логика программы была переработана из чата для двух пользователей в echo-client и echo-server.  
Сервер отвечает клиенту на то же самое сообщение и прибавляет номер сообщения от этого клиента. Могут быть подключены одновременно несколько клиентов (с разными портами). Пользователь может использовать команду "shutdown" или сигнал прерывания (^C) для того чтобы послать на сервер сообщение о закрытии, пользовательская программа закроется и счётчик для данного клиента будет обнулён. Можно подключиться вновь.  

Для передачи UDP-пакетов используются RAW-сокеты. Заголовки задаются самостоятельно в коде программы. И также при получении обработка происходит поэтапно соответствующими строками кода.

На сервере, для хранения и обработки информации о подключённых клиентах и отправленных ими сообщениях, реализован самописный односвязный список.

Для сборки программы написан Makefile  
 - Компиляция и сборка 
    >make
 - Запуск сервера
    >./serverRAW
 - Запуск сервера
    >./clientRAW \<ip-address\> \<PORT\> (ex. 127.0.2.42 5042)
 - Удаление скомпилированных файлов 
    >make clean
