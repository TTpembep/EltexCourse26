# Задание 3 по Модулю 3. Файлы.  
За основу взят код программы из задания 2.1 модуля 2.  
Программа представляет собой телефонную книгу, в которой можно создавать, изменять и удалять контакты. А также можно вывести список всех контактов.  

Код программы был изменён так, чтобы список контактов хранился в файле.  
При запуске происходит проверка наличия файла "filebook" в той же директории. Если файла нет - продолжение работы, запускается основной цикл программы.  
Если файл найден, происходит обработка данных из файла и запись их во внутреннюю структуру.  

При завершении программы происходит запись данных в файл "filebook", содержимое полностью перезаписывается.  

Для работы с файлом использован небуферизованный ввод-вывод с помощью системных вызовов: open(), read(), write(), close.  
Данные считываются и записывается блоками, которые соответствуют по размеру структуре "contact".

Для сборки программы написан Makefile
 - Компиляция и сборка 
    >make
 - Запуск программы 
    >./main
 - Удаление скомпилированных файлов, а также файла "filebook" 
    >make clean
