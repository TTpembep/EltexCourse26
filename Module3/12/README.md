# Задание 12 по Модулю 3. UDP сокеты.  
Из лекции был взят код для UDP-клиента и UDP-сервера. Но он не работал. Было выялено несколько ошибок:  
 1. У клиента порт сервера был указан "7" (который назначен стандартному UDP Echo-сервису), а у сервера был назначен порт "51000".  
 2. В примере сказано при запуске клиента указать IP-адрес вида "192.x.x.x", но это адрес в локальной сети.  

Для отладки ошибок был установлен UDP Echo-сервис с помощью xinetd и программа клиента корректно заработала при указании адреса типа "127.x.x.x" (Которые предназначены чтобы компьютер обратился сам к себе).  
Затем в приложении клиента и сервера был указан порт "51000" и передача данных завершилась успехом.

<br></br>
На основе кода из лекции реализован чат для двух клиентов с использованием UDP-сокетов. Запускается сервер, к которому должны подключиться 2 пользователя и сервер будет пересылать их сообщения друг другу. Для клиентов предусмотрено "асинхронное" взаимодействие (То есть отправка или приём сообщений в любом порядке).

Фишки:  
 1. Если уже два пользователя общаются - последующим будет выведено сообщение "Chatroom is full.".  
 2. Пользователь может отсоединиться с помощью команды "shutdown".  
 3. Сервер формирует приходящее сообщение полностью. Позволит делать сообщения >SERVER:Information либо >User4124:message.  
 4. Можно было бы сделать ещё очередь ожидания, но я и так уже накрутил намного больше чем нужно поэтому нет. 

Выявленная программная ошибка:  
Если клиент3 зайдёт когда чат будет заполнен потом чат станет свободным а он напишет только shutdown то займёт ячейку подключенных пользователей, но сам отключится.  

Для сборки программы написан Makefile  
 - Компиляция и сборка 
    >make
 - Запуск сервера
    >./serverUDP
 - Запуск сервера
    >./clientUDP \<ip-address\> (ex. 127.0.2.42)
 - Удаление скомпилированных файлов 
    >make clean
