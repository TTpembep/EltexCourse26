# Задание 6.3 по Модулю 2. Телефонная книга  
За основу взята программа из задания 2.3 модуля 2.  
В файле "main.c" код программы был изменён таким образом, чтобы функции загружались из динамических библиотек.  
Согласно заданию в одной библиотеке должна находиться одна функция, поэтому было создано 6 файлов с названиями, соответствующими функциям калькулятора.  
В заголовочном файле "calc.h" описаны обобщённые прототипы для функций с один и двумя параметрами.  

Затем файлы с функциями были собраны сначала в объектные файлы, а затем и в динамические библиотеки.
Программа была собрана с указанием параметра "-ldl". Это означает компоновку с библиотекой libdl. Эта библиотека используяется для динамической загрузки библиотек во время выполения программы.  

Команды для компиляции и запуска программы представлены в файле "1.png".
