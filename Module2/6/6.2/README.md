# Задание 6.2 по Модулю 2. Телефонная книга  
За основу взята программа из задания 6.1 модуля 2.  
Необходимо доработать решение задачи так, чтобы функции по работе с двухсвязным упорядоченным списком находились в статической библиотеке.  

Код программы уже был написан и разбит по файлам так, чтобы его можно было разделить на основую часть программы и динамическую библиотеку.  

Сначала необходимо было из файла "phonebook.c" скомпилировать объектный файл.  
Затем из объектного файла "phonebook.o" создать динамическую библиотеку "libmomemade.so".  
И затем собрать программу с подключением динамической библиотеки.  

При первой попытке запуска, в консоль была выведена ошибка что динамическая библиотека не найдена.
Для решения этой проблемы в переменную окружения "LD_LIBRARY_PATH" был указан путь до рабочей директории.
Таким образом программма была успешно запущена. Команды и результаты тестирования представлены в файле "1.png"
