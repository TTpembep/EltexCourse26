# Задание 6.1 по Модулю 2. Телефонная книга  
За основу взята программа из задания 4.1 модуля 2.  
Необходимо было доработать решение задачи так, чтобы структура и функции по работе с двухсвязным списком находились в статической библиотеке.  
Так как в заголовочном файле "phonebook.h" уже была описана структура списка и объявлены прототипы функций и в файле "phonebook.c" представлена реализация функций для работы с двухсвязным списком, необходимо было собрать статическую библиотеку.  

Сначала был скомпилирован объектный файл "phonebook.o".  
Затем на его основе была создана статическая библиотека "libhomemade.a".
И после этого программа было собрана с явным указанием того, что в текущей директории необходимо найти соответсвующую статическую библиотеку.
