# Задание 2.2 по Модулю 2. Написать простой калькулятор  
В main.c реализованы 2 функции:  
1. Функция main, которая является основным циклом программы  
    В ней происходит объявление переменных и бОльшая часть вывода информации пользователю. Также определяется какую из функций калькулятора необходимо вызвать и какие значения ей передать. Есть возможность форматирования вывода.
2. Функция numberScan  
    В данной функции происходит обработка пользовательского ввода, чтобы получить чисал, с которыми будет работать функция калькулятора.

В calc.c реализованы 6 базовых функций калькулятора. Логика выполнения вычислений отделена от основного цикла программы.

Для сборки проекта написан Makefile.  
- Сборка и запуск:
    >make  
    ./main.exe  
- Удаление скомплированных файлов:  
    >make clean
