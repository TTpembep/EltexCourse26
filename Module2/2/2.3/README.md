# Задание 2.3 по Модулю 2. Усовершенствование калькулятора  
За основу взята работа 2.2. 
В main-функции была изменена структура. Добавлены массивы указателей на функции. Затем switch-case конструкция была изменена на обращение к указателю с определённым индексом.  
Это позволило сократить общую длину кода, а также убрать повторяющиеся строки для получения данных от пользователя и вывод в консоль.  
Так как в калькуляторе реализованы бинарные и унарные операции, было создано два массива указателей и добавлены логические условия, которые позволяют определить к какому массиву необходимо обратиться

Функция numberScan в main.c и файл calc.c остались без изменений.

Для сборки проекта написан Makefile.  
- Сборка и запуск:
    >make  
    ./main.exe  
- Удаление скомплированных файлов:  
    >make clean
