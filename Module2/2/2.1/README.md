# Задание 2.1 по Модулю 2. Телефонная книга  
Реализована программа для работы со списком контактов.  
Она позволяет хранить: номер телефона, имя, фамилию, рабочее место, должность и почтовый адрес контакта.  
Обязательны для заполнения только номер телефона, имя и фамилия.  

Для хранения данных в структуре использованы статические массивы.  
Для хранения массива "телефонная книга", который состоит из нескольких структур данных "contact", выделяется динамическая память с помощью функции malloc().  
При заполнении свободных ячеек контактов и последующей попытке добавления нового контакта, для массива увеличивается размер выделенной памяти при помощи функции realloc().

Программа является консольным приложением и предоставляет пользователю возможности добавления, редактирования, удаления и просмотра списка контактов.  
Функция для удаления контактов может принимать переменное количество входных параметров.
