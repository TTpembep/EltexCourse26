# Задание 4.2 по Модулю 2. Очередь с приоритетами  
В данном задании была разработана структура данных очередь.  
Диапазон возможных приоритетов от 0 до 255, где 0 это самый высокий приоритет.  
Добавлен следующй функционал:  
1. Добавление элемента (С заданием сообщения и приоритета);
2. Извлечение элемента, который находится первым в очереди;
3. Извлечение элемента с указанным приоритетом;
4. Извлечение элемента с приоритетом не ниже чем заданным;
5. Создание тестовых сообщений случайным образом;
6. Набор тестовых вызовов функций.

В файле "main.c" описано основное меню для взаимодействия с пользователем и тестовый алгоритм.  
В файле "coolQ.c" описана внутренняя логика структуры данных очередь.  

Написан Makefile:
- Компиляция и сборка проекта `make`
- Запуск `./main.exe`
- Очистка каталога `make clean`
