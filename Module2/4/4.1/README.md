# Задание 4.1 по Модулю 2. Доработанная телефонная книга
За основу взят код из задания 2.1 модуля 2.  
Программма представляет телефонную книгу, с сортировкой контаков по фамилиям  
(Порядок сортировки A-Z a-z).  

Для хранения данных использован двухсвязный упорядоченный список.  
Реализовано динамическое выделение памяти под каждый узел.  

Основной функционал программы остался прежним, внутренняя логика переработана под использование двухсвязного списка.  
Функция удаления контакта теперь удаляет по одному контакту и не принимает переменное количество входных параметров.
